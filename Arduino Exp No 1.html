Experiment Details

Experiment: Arduino Experiment No. 1

Experiment Name: LED Blinking Using Arduino UNO

Controller: Arduino UNO R3

Output Device: LED

Programming Software: Arduino IDE

Objective: To understand basic Arduino digital output operation by turning an LED ON and OFF continuously.

Required Components

Arduino UNO R3

Main controller of the experiment.

LED

Used as the digital output.

220Ω Resistor

Limits current flowing through the LED.

Jumper Wires

Used to make circuit connections.

Breadboard

Used to assemble the circuit.

USB Cable

Connects Arduino UNO to the computer.

Circuit Connections

Component Pin Arduino Connection
LED Anode (+) Digital Pin 13 through 220Ω resistor
LED Cathode (-) GND
Arduino UNO USB Computer USB Port
Always use a current-limiting resistor with an external LED to protect both the LED and Arduino output pin.

Circuit Diagram

Connect the LED to Arduino digital pin 13 through a 220Ω resistor and connect the other LED terminal to GND.

Working Principle

Arduino digital pin 13 is configured as an output.

The program first makes pin 13 HIGH, causing current to flow through the LED and turning it ON.

After a delay of one second, pin 13 is made LOW, turning the LED OFF.

Another one-second delay is provided and the complete process repeats continuously.

Arduino Code

led_blink.ino 
const int ledPin = 13;

void setup() {

    pinMode(ledPin, OUTPUT);

}

void loop() {

    digitalWrite(ledPin, HIGH);

    delay(1000);

    digitalWrite(ledPin, LOW);

    delay(1000);

}
The value 1000 in delay(1000) represents 1000 milliseconds, which is equal to 1 second.

Steps to Perform the Experiment

  1. Place the LED on the breadboard.
  2. Connect the LED anode to Arduino digital pin 13 through a 220Ω resistor.
  3. Connect the LED cathode to Arduino GND.
  4. Connect the Arduino UNO to the computer using the USB cable.
  5. Open Arduino IDE.
  6. Select Tools → Board → Arduino UNO .
  7. Select the correct COM port.
  8. Paste the LED blinking program.
  9. Click the Verify button.
  10. Click the Upload button.
  11. Observe the LED.

Expected Output

The LED turns ON for 1 second and then turns OFF for 1 second.

This cycle repeats continuously while the Arduino is powered.
