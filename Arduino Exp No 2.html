Servo Motor Control (Servo Angle Control)

Experiment Details

Experiment: Arduino Experiment No. 2

Experiment Name: Servo Motor Control (Servo Angle Control)

Controller: Arduino UNO

Output Device: Servo Motor

Programming Software: Arduino IDE

Objective: To control the angle of a servo motor using Arduino by rotating it to different angles.

Required Components

Arduino UNO

Main controller used to control the servo motor.

Servo Motor

Used to rotate to different specified angles.

Circuit Connections

Component Pin Arduino Connection
Servo Motor Signal Digital Pin 9
Servo Motor VCC 5V
Servo Motor GND GND
The servo signal pin is connected to Arduino digital pin 9 as specified in the experiment program.

Circuit Diagram

Connect the servo motor signal wire to Arduino digital pin 9. Connect the power and ground wires to the corresponding Arduino supply pins.

Working Principle

The Servo library is included in the Arduino program and a servo object is created.

The servo signal is connected to Arduino digital pin 9 using the attach() function.

The program then rotates the servo motor to 0 degrees and waits for one second.

It then rotates to 90 degrees and waits for one second.

Finally, the servo rotates to 180 degrees and waits for one second.

This process repeats continuously.

Arduino Code

servo_motor.ino 
#include <Servo.h>

Servo myservo;

void setup() {

    myservo.attach(9);

}

void loop() {

    myservo.write(0);

    delay(1000);

    myservo.write(90);

    delay(1000);

    myservo.write(180);

    delay(1000);

}
The servo motor is programmed to move sequentially to 0°, 90°, and 180°, with a one-second delay between each position.

Steps to Perform the Experiment

  1. Connect the servo motor to the Arduino UNO.
  2. Connect the servo signal pin to Arduino digital pin 9.
  3. Connect the servo power and ground connections.
  4. Connect the Arduino UNO to the computer using the USB cable.
  5. Open Arduino IDE.
  6. Include the Servo.h library.
  7. Attach the servo signal to digital pin 9.
  8. Upload the program to the Arduino.
  9. Observe the servo motor movement.
  10. Verify that the servo rotates to 0°, 90°, and 180° continuously.

Expected Output

The servo motor rotates to 0 degrees, then to 90 degrees, and finally to 180 degrees.

Each position is maintained for approximately one second before moving to the next position.

The sequence repeats continuously.
