Experiment Details

Experiment: Raspberry Pi Experiment No. 2

Experiment Name: DHT11 Temperature & Humidity Monitoring Using Blynk

Controller: Raspberry Pi

Input Device: DHT11 Temperature and Humidity Sensor

Sensor Pin: GPIO 4 (D4)

Output Platform: Blynk IoT

Virtual Pin for Temperature: V0

Virtual Pin for Humidity: V1

Programming Language: Python

Libraries: board, adafruit_dht, BlynkLib

Objective: To read temperature and humidity values from a DHT11 sensor connected to the Raspberry Pi and send the readings to Blynk for remote monitoring.

Required Components

Raspberry Pi

Main controller used to read the DHT11 sensor.

DHT11 Sensor

Measures temperature and humidity.

WiFi / Internet

Used to communicate with the Blynk platform.

Blynk IoT Platform

Displays the temperature and humidity values remotely.

Jumper Wires

Used to make the required sensor connections.

Breadboard

Used for assembling the sensor circuit.

Circuit Connections

Component Pin Raspberry Pi Connection
DHT11 DATA GPIO 4 (D4)
DHT11 VCC Raspberry Pi Power Supply
DHT11 GND Raspberry Pi GND
The DHT11 sensor data line is connected to Raspberry Pi GPIO 4, represented as D4 in the Python program.

Circuit Diagram

Connect the DHT11 sensor data pin to Raspberry Pi GPIO 4 (D4). Connect the sensor power and ground to the appropriate Raspberry Pi supply pins.

Working Principle

The Python program imports the required libraries for time handling, Raspberry Pi pin access, DHT11 sensor reading, and Blynk communication.

The DHT11 sensor is initialized using board.D4 , which corresponds to Raspberry Pi GPIO 4.

The program continuously runs blynk.run() to maintain communication with the Blynk platform.

The temperature and humidity values are read from the DHT11 sensor.

When valid readings are available, the temperature is printed to the terminal and sent to Blynk virtual pin V0 .

The humidity value is sent to Blynk virtual pin V1 .

The program waits for approximately two seconds before taking the next reading.

Python Code

dht11_blynk.py 
import time

import board

import adafruit_dht

import BlynkLib


# Replace with your Blynk Auth Token

BLYNK_AUTH = "YOUR_BLYNK_AUTH_TOKEN"

blynk = BlynkLib.Blynk(BLYNK_AUTH)


# DHT11 connected to GPIO4 (D4)

dht = adafruit_dht.DHT11(board.D4)


while True:

    blynk.run()

    try:

        temperature = dht.temperature

        humidity = dht.humidity

        if temperature is not None and humidity is not None:

            print("Temperature:", temperature, "C")

            print("Humidity:", humidity, "%")

            # Send values to Blynk

            blynk.virtual_write(
                0,
                temperature
            )  # V0

            blynk.virtual_write(
                1,
                humidity
            )  # V1

    except RuntimeError:

        pass

    time.sleep(2)
Replace YOUR_BLYNK_AUTH_TOKEN with the Blynk authentication token associated with your Blynk device.

Steps to Perform the Experiment

  1. Connect the DHT11 sensor to the Raspberry Pi.
  2. Connect the DHT11 data pin to GPIO 4 (D4).
  3. Connect the sensor power and ground connections.
  4. Make sure the Raspberry Pi has an internet connection.
  5. Open the Python development environment or terminal.
  6. Install and import the required libraries.
  7. Create a Blynk device and obtain the Blynk authentication token.
  8. Enter the Blynk Auth Token in the Python program.
  9. Configure Blynk virtual pin V0 for temperature.
  10. Configure Blynk virtual pin V1 for humidity.
  11. Run the Python program.
  12. Observe the temperature and humidity values on the terminal and Blynk dashboard.

Expected Output

The terminal displays the measured temperature in degrees Celsius.

The terminal also displays the measured humidity percentage.

The temperature value is sent to Blynk virtual pin V0 .

The humidity value is sent to Blynk virtual pin V1 .

The readings are continuously updated at approximately two-second intervals.
