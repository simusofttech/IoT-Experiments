Experiment Details

Experiment: ESP32-CAM Experiment No. 2

Experiment Name: WiFi Camera Server and Live Video Streaming

Controller: ESP32-CAM AI-THINKER

Camera Model: AI-THINKER

Communication: WiFi

Image Format: JPEG

Programming Software: Arduino IDE

Objective: To configure the ESP32-CAM, connect it to a WiFi network, start the camera server, and access the camera stream through the ESP32-CAM IP address.

Required Components

ESP32-CAM AI-THINKER

Main controller and camera module used for image capture and streaming.

Camera Module

Captures images and video for the live camera stream.

WiFi Network

Provides wireless communication between the ESP32-CAM and computer.

USB / Serial Programmer

Used to upload the program to the ESP32-CAM.

Camera Setup

Select the CAMERA_MODEL_AI_THINKER option in the program and use the corresponding camera pin definitions from camera_pins.h.

Working Principle

The program first initializes serial communication at 115200 baud.

The ESP32-CAM camera is configured using the camera configuration structure and the AI-THINKER camera pin definitions.

The camera is configured to capture images in JPEG format.

If PSRAM is available, the camera uses QVGA resolution of 320 × 240 pixels.

The program then initializes the camera and applies sensor settings such as brightness, contrast, saturation, white balance, gain control, and exposure control.

The ESP32-CAM is then connected to the configured WiFi network.

After the WiFi connection is established, the camera server is started.

The ESP32-CAM local IP address is displayed on the Serial Monitor. This IP address can be entered into a browser to access the camera server.

Arduino Code

esp32_cam_camera_server.ino 
#include "esp_camera.h"

#include <WiFi.h>

// =================== CAMERA MODEL ===================

#define CAMERA_MODEL_AI_THINKER

#include "camera_pins.h"

// =================== WIFI CONFIG ====================

const char* ssid =
"YOUR_WIFI_NAME";

const char* password =
"YOUR_WIFI_PASSWORD";

void startCameraServer();

// =================== SETUP FUNCTION ===================

void setup() {

    Serial.begin(115200);

    Serial.setDebugOutput(false);

    Serial.println();

    // =================== CAMERA CONFIG ===================

    camera_config_t config;

    config.ledc_channel = LEDC_CHANNEL_0;

    config.ledc_timer = LEDC_TIMER_0;

    config.pin_d0 = Y2_GPIO_NUM;

    config.pin_d1 = Y3_GPIO_NUM;

    config.pin_d2 = Y4_GPIO_NUM;

    config.pin_d3 = Y5_GPIO_NUM;

    config.pin_d4 = Y6_GPIO_NUM;

    config.pin_d5 = Y7_GPIO_NUM;

    config.pin_d6 = Y8_GPIO_NUM;

    config.pin_d7 = Y9_GPIO_NUM;

    config.pin_xclk = XCLK_GPIO_NUM;

    config.pin_pclk = PCLK_GPIO_NUM;

    config.pin_vsync = VSYNC_GPIO_NUM;

    config.pin_href = HREF_GPIO_NUM;

    config.pin_sscb_sda = SIOD_GPIO_NUM;

    config.pin_sscb_scl = SIOC_GPIO_NUM;

    config.pin_pwdn = PWDN_GPIO_NUM;

    config.pin_reset = RESET_GPIO_NUM;

    config.xclk_freq_hz = 20000000;

    config.pixel_format = PIXFORMAT_JPEG;

    // =================== STREAM OPTIMIZATION ===================

    if (psramFound()) {

        config.frame_size = FRAMESIZE_QVGA;

        config.jpeg_quality = 12;

        config.fb_count = 1;

    }

    else {

        config.frame_size = FRAMESIZE_QQVGA;

        config.jpeg_quality = 15;

        config.fb_count = 1;

    }

    // =================== INIT CAMERA ===================

    esp_err_t err = esp_camera_init(&config);

    if (err != ESP_OK) {

        Serial.printf(
            "Camera init failed: 0x%x\n",
            err
        );

        return;

    }

    // =================== SENSOR TUNING ===================

    sensor_t * s =
        esp_camera_sensor_get();

    s->set_framesize(
        s,
        FRAMESIZE_QVGA
    );

    s->set_quality(
        s,
        12
    );

    s->set_brightness(
        s,
        0
    );

    s->set_contrast(
        s,
        0
    );

    s->set_saturation(
        s,
        -1
    );

    s->set_whitebal(
        s,
        1
    );

    s->set_gain_ctrl(
        s,
        1
    );

    s->set_exposure_ctrl(
        s,
        1
    );

    if (s->id.PID == OV3660_PID) {

        s->set_vflip(
            s,
            1
        );

    }

    // =================== WIFI SETUP ===================

    WiFi.mode(WIFI_STA);

    WiFi.setSleep(false);

    WiFi.begin(
        ssid,
        password
    );

    Serial.print(
        "Connecting to WiFi"
    );

    while (
        WiFi.status() != WL_CONNECTED
    ) {

        delay(300);

        Serial.print(".");

    }

    Serial.println(
        "\nWiFi connected"
    );

    // =================== START SERVER ===================

    startCameraServer();

    Serial.print(
        "Camera Stream Ready! Visit: http://"
    );

    Serial.println(
        WiFi.localIP()
    );

}

// =================== LOOP FUNCTION ===================

void loop() {

    delay(1);

}
Replace YOUR_WIFI_NAME and YOUR_WIFI_PASSWORD with the WiFi credentials you want to use before uploading the program.

Steps to Perform the Experiment

  1. Connect the ESP32-CAM to the computer using a suitable programming interface.
  2. Open Arduino IDE.
  3. Select the AI Thinker ESP32-CAM board.
  4. Include the required esp_camera.h and WiFi.h libraries.
  5. Select CAMERA_MODEL_AI_THINKER .
  6. Enter the correct WiFi SSID and password in the program.
  7. Upload the program to the ESP32-CAM.
  8. Open the Serial Monitor and set the baud rate to 115200 .
  9. Wait for the ESP32-CAM to connect to the WiFi network.
  10. Note the IP address displayed in the Serial Monitor.
  11. Enter the displayed IP address in a web browser connected to the same network.
  12. Access the camera server and view the camera stream.

Expected Output

The ESP32-CAM successfully connects to the configured WiFi network.

The Serial Monitor displays:

WiFi connected

The local IP address of the ESP32-CAM is then displayed.

Opening this IP address in a browser provides access to the ESP32-CAM camera server and live camera stream.
