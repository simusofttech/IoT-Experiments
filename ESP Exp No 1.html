Experiment Details

Experiment: ESP32-CAM Experiment No. 1

Experiment Name: LED Control Using ESP32-CAM

Controller: ESP32-CAM

Input Device: Tactile Switch / Potentiometer

Output Device: Onboard LED

LED Pin: GPIO 4

Programming Software: Arduino IDE

Objective: To control the onboard LED of the ESP32-CAM using basic digital output, a push button, and PWM-based brightness control.

Required Components

ESP32-CAM

Main controller with an onboard LED connected to GPIO 4.

Tactile Switch

Used to control the onboard LED in Code-2.

Potentiometer

Used to control LED brightness in Code-3.

Jumper Wires

Used for making the required circuit connections.

Circuit Connections

Component Pin ESP32-CAM Connection
Onboard LED LED_PIN GPIO 4
Tactile Switch BUTTON_PIN GPIO 13
Potentiometer Middle Pin GPIO 13
Tactile Switch Other Pin GND
The ESP32-CAM onboard LED is controlled through GPIO 4. Code-2 uses GPIO 13 for the tactile switch, while Code-3 uses GPIO 13 for the potentiometer.

Circuit Diagram

Connect the required external components according to the respective code. The onboard LED is connected to GPIO 4.

Working Principle

Code-1: The onboard LED connected to GPIO 4 is configured as an output. The LED is turned ON and OFF alternately with a delay of 500 milliseconds.

Code-2: The tactile switch is connected to GPIO 13 and configured with the internal pull-up resistor. When the button is pressed, the LED turns ON. When the button is released, the LED turns OFF.

Code-3: The potentiometer connected to GPIO 13 provides an analog value. This value is mapped from 0–4095 to 0–255 and used to control the brightness of the onboard LED using PWM.

Code-1: Onboard LED Blinking

code_1.ino 
#define LED_PIN 4

void setup() {

    pinMode(LED_PIN, OUTPUT);

}

void loop() {

    digitalWrite(LED_PIN, HIGH);

    delay(500);

    digitalWrite(LED_PIN, LOW);

    delay(500);

}
The ESP32-CAM onboard LED is connected to GPIO 4. Changing the delay value changes the blinking speed of the LED.

Code-2: LED Control Using Tactile Switch

code_2.ino 
#define LED_PIN 4

#define BUTTON_PIN 13

void setup() {

    pinMode(LED_PIN, OUTPUT);

    pinMode(BUTTON_PIN, INPUT_PULLUP);

    digitalWrite(LED_PIN, LOW);

}

void loop() {

    int buttonState =
        digitalRead(BUTTON_PIN);

    if (buttonState == LOW) {

        digitalWrite(LED_PIN, HIGH);

    } else {

        digitalWrite(LED_PIN, LOW);

    }

}
The button uses INPUT_PULLUP. When the button is pressed, the input becomes LOW because it is connected to GND.

Code-3: LED Brightness Control Using Potentiometer

code_3.ino 
#define LED_PIN 4

#define POT_PIN 13

#define PWM_FREQ 5000

#define PWM_RESOLUTION 8

void setup() {

    ledcAttach(
        LED_PIN,
        PWM_FREQ,
        PWM_RESOLUTION
    );

    pinMode(POT_PIN, INPUT);

}

void loop() {

    int potValue =
        analogRead(POT_PIN);

    int brightness =
        map(
            potValue,
            0,
            4095,
            0,
            255
        );

    ledcWrite(
        LED_PIN,
        brightness
    );

    delay(10);

}
The potentiometer reading is converted from the ESP32 analog range of 0–4095 to a brightness range of 0–255.

Steps to Perform the Experiment

  1. Connect the ESP32-CAM to the computer.
  2. Open Arduino IDE.
  3. Select the appropriate ESP32-CAM board from the board options.
  4. Select the correct COM port.
  5. Upload Code-1 and observe the onboard LED blinking.
  6. Connect the tactile switch to GPIO 13 and upload Code-2.
  7. Press the switch and observe the LED.
  8. Connect the potentiometer to GPIO 13 and upload Code-3.
  9. Rotate the potentiometer and observe the change in LED brightness.

Expected Output

Code-1: The onboard LED blinks continuously, turning ON and OFF every 500 milliseconds.

Code-2: The onboard LED turns ON when the tactile switch is pressed and turns OFF when it is released.

Code-3: The onboard LED brightness changes as the potentiometer is rotated.
