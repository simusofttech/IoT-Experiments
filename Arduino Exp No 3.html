Experiment Details

Experiment: Arduino Experiment No. 3

Experiment Name: Rain Detection Sensor

Controller: Arduino UNO

Input Device: Rain Detection Sensor

Output Device: Buzzer

Programming Software: Arduino IDE

Objective: To detect water or rain using a rain detection sensor and activate a buzzer when the sensor value crosses the specified threshold.

Required Components

Arduino UNO

Main controller used to read the rain sensor value.

Rain Detection Sensor

Detects the presence of water or rain and provides an analog output.

Buzzer

Provides an audible indication when water is detected.

Jumper Wires

Used to make the circuit connections.

Breadboard

Used to assemble the circuit.

USB Cable

Connects Arduino UNO to the computer.

Circuit Connections

Component Pin Arduino Connection
Rain Sensor Analog Output A0
Buzzer Positive / Signal Digital Pin 8
Buzzer Negative GND
The rain sensor is connected to analog pin A0, while the buzzer is connected to digital pin 8.

Circuit Diagram

Connect the analog output of the rain sensor to Arduino pin A0. Connect the buzzer to digital pin 8 and GND.

Working Principle

The rain sensor is connected to Arduino analog pin A0 and continuously provides an analog value between 0 and 1023.

The Arduino reads this sensor value using the analogRead() function.

The sensor value is also displayed on the Serial Monitor using Serial.println().

When the sensor value is greater than 500, the buzzer is turned ON.

When the value is 500 or less, the buzzer is turned OFF.

This process repeats continuously with a short delay for stable operation.

Arduino Code

rain_detection.ino 
int sensor = A0;   // Rain sensor connected to A0

int buzzer = 8;    // Buzzer connected to digital pin 8

void setup() {

    pinMode(buzzer, OUTPUT);   // Set buzzer pin as output

    Serial.begin(9600);        // Initialize serial communication

}

void loop() {

    int value = analogRead(sensor);   // Read sensor value (0–1023)

    Serial.println(value);             // Display value on Serial Monitor

    if (value > 500) {                 // Threshold for water detection

        digitalWrite(buzzer, HIGH);    // Turn ON buzzer

    } else {

        digitalWrite(buzzer, LOW);     // Turn OFF buzzer

    }

    delay(200);                        // Small delay for stability

}
The threshold value is set to 500. When the sensor reading is greater than 500, the buzzer is switched ON.

Steps to Perform the Experiment

  1. Connect the rain detection sensor to the Arduino UNO.
  2. Connect the sensor analog output to Arduino pin A0.
  3. Connect the buzzer to digital pin 8 and GND.
  4. Connect the Arduino UNO to the computer using the USB cable.
  5. Open Arduino IDE.
  6. Select the correct Arduino board and COM port.
  7. Enter the rain detection program.
  8. Click the Verify button.
  9. Upload the program to the Arduino.
  10. Open the Serial Monitor and set the baud rate to 9600.
  11. Apply water to the rain sensor and observe the sensor value.
  12. Observe the buzzer operation based on the sensor threshold.

Expected Output

The rain sensor value is continuously displayed on the Serial Monitor.

When the sensor value is greater than 500, the buzzer turns ON.

When the sensor value is 500 or less, the buzzer turns OFF.

The sensor reading and buzzer status are continuously updated.
