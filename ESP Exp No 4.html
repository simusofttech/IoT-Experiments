Experiment Details

Experiment: ESP32-CAM Experiment No. 4

Experiment Name: Camera Capture and Photo Storage on SD Card

Controller: ESP32-CAM

Camera: ESP32-CAM Camera Module

Storage: SD Card using SD_MMC

Communication: WiFi

Web Server: ESP32 WebServer

Output: Live Camera Stream and Captured Photograph

Programming Software: Arduino IDE

Objective: To create an ESP32-CAM web application that provides live video streaming and captures photographs which are stored on an SD card.

Required Components

ESP32-CAM

Main controller used for image capture and web streaming.

Camera Module

Captures the images used for the live stream and photographs.

Micro SD Card

Used to store captured photographs.

WiFi Network

Provides wireless access to the ESP32-CAM web server.

Computer / Smartphone

Used to access the live camera webpage.

Circuit Diagram

Connect the ESP32-CAM camera module to the board and insert a compatible micro SD card into the SD card slot.

Working Principle

The ESP32-CAM is configured to capture images in JPEG format at QVGA resolution.

The camera is initialized and the image is vertically flipped using the camera sensor settings.

The ESP32-CAM connects to the configured WiFi network and starts a web server.

When the browser accesses the main webpage, it displays the ESP32-CAM live stream and a button for capturing photographs.

The /stream route continuously sends JPEG camera frames to the connected browser.

When the Capture Photo button is pressed, a new camera frame is captured.

The captured image is saved to the SD card with a filename based on the elapsed milliseconds.

The webpage then displays a message indicating whether the photograph was successfully saved.

#include "esp_camera.h"

// =================== SETUP ===================

void setup() {

    Serial.begin(115200);

    camera_config_t config;

    config.ledc_channel =
        LEDC_CHANNEL_0;

    config.ledc_timer =
        LEDC_TIMER_0;

    config.pin_d0 =
        Y2_GPIO_NUM;

    config.pin_d1 =
        Y3_GPIO_NUM;

    config.pin_d2 =
        Y4_GPIO_NUM;

    config.pin_d3 =
        Y5_GPIO_NUM;

    config.pin_d4 =
        Y6_GPIO_NUM;

    config.pin_d5 =
        Y7_GPIO_NUM;

    config.pin_d6 =
        Y8_GPIO_NUM;

    config.pin_d7 =
        Y9_GPIO_NUM;

    config.pin_xclk =
        XCLK_GPIO_NUM;

    config.pin_pclk =
        PCLK_GPIO_NUM;

    config.pin_vsync =
        VSYNC_GPIO_NUM;

    config.pin_href =
        HREF_GPIO_NUM;

    config.pin_sccb_sda =
        SIOD_GPIO_NUM;

    config.pin_sccb_scl =
        SIOC_GPIO_NUM;

    config.pin_pwdn =
        PWDN_GPIO_NUM;

    config.pin_reset =
        RESET_GPIO_NUM;

    config.xclk_freq_hz =
        13000000;

    config.pixel_format =
        PIXFORMAT_JPEG;

    config.frame_size =
        FRAMESIZE_QVGA;

    config.jpeg_quality =
        10;

    config.fb_count =
        1;

    config.grab_mode =
        CAMERA_GRAB_LATEST;


    // Initialize camera

    esp_err_t err =
        esp_camera_init(
            &config
        );

    if (err != ESP_OK) {

        Serial.printf(
            "Camera init failed with error 0x%x\n",
            err
        );

        return;

    }

    Serial.println(
        "Camera initialized successfully!"
    );


    sensor_t *s =
        esp_camera_sensor_get();

    s->set_vflip(
        s,
        1
    );


    // =================== SD CARD ===================

    if (
        !SD_MMC.begin(
            "/sdcard",
            true
        )
    ) {

        Serial.println(
            "SD Card Failed or Not Present"
        );

    }

    else {

        Serial.println(
            "SD Card Mounted"
        );

    }


    // =================== WIFI ===================

    Serial.print(
        "Connecting to WiFi"
    );

    WiFi.begin(
        ssid,
        password
    );

    int attempts = 0;

    while (
        WiFi.status() != WL_CONNECTED &&
        attempts < 20
    ) {

        delay(500);

        Serial.print(".");

        attempts++;

    }


    if (
        WiFi.status() == WL_CONNECTED
    ) {

        Serial.println(
            "\nWiFi Connected!"
        );

        Serial.print(
            "Camera URL: http://"
        );

        Serial.println(
            WiFi.localIP()
        );

    }

    else {

        Serial.println(
            "\nWiFi Failed!"
        );

    }


    // =================== WEB ROUTES ===================

    server.on(
        "/",
        []() {

            server.send_P(
                200,
                "text/html",
                HTML_PAGE
            );

        }
    );


    server.on(
        "/stream",
        HTTP_GET,
        []() {

            WiFiClient client =
                server.client();

            client.println(
                "HTTP/1.1 200 OK"
            );

            client.println(
                "Content-Type: multipart/x-mixed-replace; boundary=frame"
            );

            client.println();

            streamClient =
                client;

        }
    );


    server.on(
        "/capture",
        HTTP_GET,
        []() {

            if (streamClient) {

                streamClient.stop();

            }


            camera_fb_t *fb =
                esp_camera_fb_get();


            if (!fb) {

                server.send(
                    500,
                    "text/plain",
                    "Camera capture failed"
                );

                return;

            }


            // Save to SD card

            String filename =
                "/photo_" +
                String(millis()) +
                ".jpg";


            File file =
                SD_MMC.open(
                    filename,
                    FILE_WRITE
                );


            if (file) {

                file.write(
                    fb->buf,
                    fb->len
                );

                file.close();


                Serial.println(
                    "Photo saved: " +
                    filename
                );


                server.send(
                    200,
                    "text/plain",
                    "Photo saved: " +
                    filename
                );

            }

            else {

                server.send(
                    500,
                    "text/plain",
                    "SD card write failed"
                );

            }


            esp_camera_fb_return(
                fb
            );

        }
    );


    server.begin();

    Serial.println(
        "HTTP server started"
    );

}


// =================== LOOP ===================

void loop() {

    server.handleClient();


    if (
        streamClient &&
        streamClient.connected()
    ) {

        camera_fb_t *fb =
            esp_camera_fb_get();


        if (fb) {

            streamClient.print(
                "--frame\r\n"
            );

            streamClient.print(
                "Content-Type: image/jpeg\r\n\r\n"
            );

            streamClient.write(
                fb->buf,
                fb->len
            );

            streamClient.print(
                "\r\n"
            );


            esp_camera_fb_return(
                fb
            );

        }


        delay(30);

    }

}
Enter your WiFi SSID and password in the program before uploading it. A compatible micro SD card should also be inserted into the ESP32-CAM before using the photo storage feature.

Steps to Perform the Experiment

  1. Insert a compatible micro SD card into the ESP32-CAM.
  2. Connect the ESP32-CAM to the computer using a suitable programming interface.
  3. Open Arduino IDE.
  4. Select the appropriate ESP32-CAM board.
  5. Enter the WiFi network name and password in the program.
  6. Upload the program to the ESP32-CAM.
  7. Open the Serial Monitor and set the baud rate to 115200 .
  8. Wait until the camera is initialized and the SD card is mounted.
  9. Wait for the ESP32-CAM to connect to the WiFi network.
  10. Note the camera URL displayed in the Serial Monitor.
  11. Open the displayed IP address in a web browser connected to the same network.
  12. Observe the live camera stream.
  13. Click Capture Photo to take a photograph.
  14. Check the SD card for the saved photograph.

Expected Output

The Serial Monitor displays that the camera has been initialized successfully.

The SD card is mounted successfully and the ESP32-CAM connects to the configured WiFi network.

The ESP32-CAM IP address is displayed in the Serial Monitor.

Opening the IP address in a browser displays the live camera stream.

Pressing Capture Photo captures an image and saves it to the SD card.

A message such as Photo saved: /photo_XXXX.jpg is displayed after successful storage.
