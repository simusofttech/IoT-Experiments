Experiment Details

Experiment: Raspberry Pi Experiment No. 1

Experiment Name: Button Controlled LED Using GPIO

Controller: Raspberry Pi

Input Device: Push Button

Output Device: LED

LED GPIO Pin: GPIO 17

Button GPIO Pin: GPIO 27

Programming Language: Python

Library: gpiozero

Objective: To control an LED using a push button connected to Raspberry Pi GPIO pins and toggle the LED whenever the button is pressed.

Required Components

Raspberry Pi

Main controller used to read the button and control the LED.

LED

Output device connected to GPIO 17.

Push Button

Input device connected to GPIO 27.

Resistor

Used with the LED as required for current limiting.

Breadboard

Used to assemble the circuit.

Jumper Wires

Used to make the required connections.

Circuit Connections

Component Pin Raspberry Pi Connection
LED Signal / Anode GPIO 17
Push Button Signal GPIO 27
Push Button Other Terminal GND
The program uses GPIO 17 for the LED and GPIO 27 for the push button.

Circuit Diagram

Connect the LED to GPIO 17 and the push button to GPIO 27. The button is configured using the gpiozero Button class.

Working Principle

The program imports the LED and Button classes from the gpiozero library.

The LED object is assigned to GPIO 17, and the button object is assigned to GPIO 27.

A function named pressed() is executed whenever the button is pressed.

Inside this function, the message "Button Pressed! LED Toggled" is printed and the LED state is changed using the toggle() function.

The when_pressed event connects the button press to the pressed() function.

The pause() function keeps the program running and waits for button press events.

Python Code

button_led.py 
from gpiozero import LED, Button

from signal import pause

led = LED(17)

button = Button(27)

def pressed():

    print("Button Pressed! LED Toggled")

    led.toggle()

button.when_pressed = pressed

print("Ready... Press button to toggle LED")

pause()
The gpiozero library provides simple Python classes for controlling Raspberry Pi GPIO devices.

Steps to Perform the Experiment

  1. Connect the LED to Raspberry Pi GPIO 17.
  2. Connect the push button to GPIO 27 and GND.
  3. Power ON the Raspberry Pi.
  4. Open the Python environment or terminal.
  5. Make sure the gpiozero library is available.
  6. Create a Python file named button_led.py .
  7. Enter the given Python program.
  8. Run the Python program.
  9. The terminal displays Ready... Press button to toggle LED .
  10. Press the push button and observe the LED.

Expected Output

When the program starts, the terminal displays:

Ready... Press button to toggle LED

Whenever the button is pressed, the LED changes its current state.

The terminal displays:

Button Pressed! LED Toggled

Each button press toggles the LED between ON and OFF.
